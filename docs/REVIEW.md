## 优化范围

6、9、18、39、43、48、49、50、54、59、60、77、78、107 号的纯位移、填充或扩散部分改用 `transform`。例如 49 / 50 / 54 号在固定容器中以像素位移取代 `top` / `left` 更新，48 / 77 / 107 号以缩放取代宽高扩散。

缩放会同时缩放边框和阴影，与原来直接修改宽高相比存在细微外观差别，仍需视觉复核。部分文字间距、颜色、阴影、模糊、几何形变和尺寸变化本身就是效果的一部分，予以保留。没有宣称所有示例都只使用合成属性，也没有给出未经实测的帧率或性能提升百分比。

共享画布采用整体缩放，集合只加载可见预览、分页限制同时保留的 iframe 数量。离屏与后台暂停，详情打开后暂停背景预览。减少动态效果偏好会默认暂停，可由用户主动开启。计数器不依赖固定次数的 `setInterval`，基于实际时间计算并在暂停 / 后台时停止调度。

## 已执行的逻辑测试

1. 计数器按实际时间更新，暂停后不增长，恢复后按 2× 速度前进并停止调度。
2. 系统减少动态效果时默认暂停，仅主动播放才覆盖偏好。
3. 页面转入后台冻结计数器，返回后不会补算整个后台时长。
4. 非父窗口或不同来源的消息不能改变播放状态。
5. 60 号场景在预定时刻完成，105 号计数到 100 后触发退场。
6. 分类、编号、标签、空结果、重置和带筛选链接的页码恢复。
7. 集合预览按可见性创建，详情重播替换 iframe，关闭后卸载详情。
8. 集合显示减少动态效果提示，并允许主动播放。
